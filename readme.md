# Proyecto E-Commerce

## Descripción
Este proyecto es una plataforma de comercio electrónico desarrollada con Spring Boot (backend) y Angular (frontend). La aplicación permite a los usuarios navegar por productos, agregarlos al carrito, realizar compras, gestionar pagos y hacer seguimiento de sus pedidos.

## Estructura del Proyecto
- **Backend**: API RESTful desarrollada con Spring Boot
- **Frontend**: Interfaz de usuario desarrollada con Angular

## Características Principales
- Catálogo de productos
- Sistema de carrito de compras
- Gestión de usuarios y autenticación
- Procesamiento de pagos
- Seguimiento de pedidos
- Sistema de reseñas y calificaciones

## Tecnologías
- **Backend**: Java, Spring Boot, Spring Data JPA, Spring Security
- **Frontend**: Angular, TypeScript, HTML, CSS
- **Base de datos**: Por definir (MySQL/PostgreSQL)
